# Engineering Skills Pack

## این چیست؟

یک سیستم بررسی مهندسیِ repository برای Claude.

پروژه را می‌فهمد، از دید تخصص‌های مختلف بررسی‌اش می‌کند، مشکلات واقعی را با شواهد
گزارش می‌دهد، و اولویت‌بندی‌شان می‌کند.

## من باهاش چه کار می‌کنم؟

repository پروژه‌ات را در **Claude Desktop** در دسترس Claude می‌گذاری و می‌گویی:

> «این پروژه رو بررسی کن.»

یا اگر فقط یک حوزه را می‌خواهی:

> «فقط امنیت این پروژه رو بررسی کن.»

همین. نه دستوری، نه نصبی، نه مسیری که باید بلد باشی.

## چه چیزی تحویل می‌گیرم؟

فهرستی از مشکلات واقعی که:

- **اولویت‌بندی شده‌اند** — مهم‌ترین اول
- **شواهد دارند** — فایل و خط و کدِ واقعی، نه توصیهٔ کلی
- **دلیل دارند** — چرا این یک مشکل است و اگر رها شود چه می‌شود
- **قابل بررسی‌اند** — چطور می‌توانی خودت درستی‌شان را چک کنی
- **صادق‌اند** — چیزی که مطمئن نیست، به‌عنوان «نیازمند بررسی» علامت می‌خورد

و اگر مشکلی پیدا نشد، همین را می‌گوید. گزارش برای پر شدن پر نمی‌شود.

## دو اصلی که این پروژه روی آن‌ها بنا شده

**۱. شواهد یا سکوت.**
هیچ مشکلی بدون فایل و خط و کدِ واقعی گزارش نمی‌شود.
گزارشی که چیزی پیدا نکرده، اگر صادقانه باشد، یک گزارش خوب است.
→ [`shared/trust-model.md`](shared/trust-model.md)

**۲. تحقیق قبل از ساخت.**
هیچ بخشی از سیستم از حافظهٔ مدل ساخته نمی‌شود. برای هر حوزهٔ تخصصی، اول از منابع
معتبر مطالعه می‌شود و یافته‌ها ثبت می‌شوند.
→ [`research/`](research/)
